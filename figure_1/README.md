# figure_1 — MSK-Tox Figure 1 and Supplementary Figure 1

Scripts that generate Figure 1 and Supplementary Figure 1 (S1A–S1K).

No source data is included here. Inputs are expected at
`figures/figures_data/figure 1/data` (same layout as the working OneDrive tree).
Notebooks assume they are run from a `figure 1/scripts/` equivalent of that tree.

## Layout

| path | holds |
|---|---|
| `code/` | Figure 1 and S1 notebooks and helper Python scripts |
